# 기출 빈도 분석 (국가기술자격 필기)

기출 문항을 개념 단위로 묶어 출제 빈도를 세고, 공부 범위를 압축하기 위한 작업 공간입니다.
현재 단계: **2단계** — 소방설비기사(전기분야) 필기 4과목, 2016년 1회 ~ 2026년 1회 31회차(공개 기출 20 + CBT 복원 11), 2,480문항.

## 산출물 (`output/`)

| 파일 | 내용 |
|---|---|
| `1_원본데이터.csv` | 문항 원문·보기·정답 (저장소에는 올리지 않음, 아래 참고) |
| `2_개념빈도표.csv` | 개념ID별 등급, 출제 회차 수, 대표 문항 |
| `3_압축학습목록.md` | 과목별 학습 대상 개념 + 공식/법조문 + 대표 문제 |
| `4_공식모음.csv` | 과목별·빈도순 공식 |
| `5_킬러목록.csv` | 버릴지 판단할 개념 (난이도·빈도) |
| `6_요약리포트.md` | 커버율, 과락 위험, 수집 사이트 현황, 불확실한 점 |

## 다시 만드는 법

```bash
python3 scripts/analyze.py   # 킬러 = 1회만 출제, 단골 기준은 '단골만으로 합격'하는 범위를 자동 탐색 (--regular 로 직접 지정 가능)
```

- `data/tags/tags.csv`: 문항별 개념ID·요지·개정무효 (직접 수정 가능)
- `data/tags/concepts.csv`: 개념 사전 (출제기준 항목, 핵심내용, 공식, 법조문)
- `data/taxonomy/`: 큐넷 출제기준(2026~2027 적용)에서 만든 분류 체계
- `data/sources.csv`: 출처별 robots.txt 확인 결과와 수집 여부

원자료부터 다시 만드는 순서: `collect_public.sh`(공개 기출) → `parse_moducbt.py`(전자책 PDF) →
`build_dataset.py`(통합·정답 교차검증) → `prep_tagging.py` → 분류 → `validate_tags.py` → `export_tags.py` → `analyze.py`

## 원문 비공개

기출 원문은 개인 학습용이며 재배포하지 않습니다. `data/raw/`와 `output/1_원본데이터.csv`는
`.gitignore`로 제외했습니다. 공개 기출은 수집 스크립트로 다시 만들 수 있고, 복원 회차는 구매한 전자책 PDF가 있어야 합니다.

## 학습 사이트 (`docs/`)

GitHub Pages로 여는 정적 사이트입니다. 빌드 과정 없이 `docs/` 폴더가 그대로 사이트가 됩니다.

- **개념 학습**: 단골 개념 256개를 비전공자 눈높이로 설명 (쉬운 설명 · 시험 포인트 · 풀이 예시 · 바로 풀어 보기)
- **문제 은행**: 단골 개념별로 새로 만든 연습 문제 768개. 한 문제씩 바로 채점 / 과목당 20문항 모의고사(과락·합격 판정) / 틀렸던 문제만
- **내 기출**: 갖고 있는 `1_원본데이터.csv`를 브라우저에서 불러와 실제 기출로 풀기. 파일은 브라우저에만 저장되고 사이트에는 올라가지 않습니다.

켜는 법: 저장소 Settings → Pages → Source "Deploy from a branch" → 브랜치와 `/docs` 폴더 선택 → Save.
주소는 `https://<계정>.github.io/<저장소>/` 입니다. 무료 요금제에서는 저장소가 공개(public)여야 합니다.

내용을 고치려면 `data/site/<과목>_lessons.jsonl`을 수정하고 `python3 scripts/build_site.py`를 실행합니다.
설명과 문제는 AI가 쓴 것이며 법령 원문과 대조하지 않았습니다. "확인 필요" 표시가 있는 개념(83개)은 현행 법령·교재로 확인하세요.
