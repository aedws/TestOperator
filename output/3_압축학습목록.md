# 과목별 압축 학습 목록

- 대상: 소방설비기사(전기) 필기 / 분석 회차 2개 (2022년 1회, 2022년 2회)
- 등급 기준: 단골 ≥ 50%, 가끔 ≥ 15%, 그 미만 킬러 — 회차가 2개뿐이라 등급은 **잠정**입니다.

## 소방원론

학습 범위: 단골 + 가끔 (단골만으로는 과락 기준 미달 → 가끔까지 확대)

### 1. 연소이론 > 1. 연소 및 연소현상

- **열에너지원(점화원)의 분류** `원론-열원-01` — 단골(잠정), 2/2회 출제(3문항), 평균 정답률 77%
  - 핵심: 화학열(연소열·분해열·용해열·자연발열) / 전기열(저항열·유도열·유전열·아크열·정전기열) / 기계열(마찰·압축). 융해열·기화열은 점화원 아님
  - 대표 문제: 2022년 2회 13번 — 점화원이 아닌 것(융해열) 포함 복합 지문
- **자연발화 조건과 방지대책** `원론-자연발화-01` — 단골(잠정), 2/2회 출제(2문항), 평균 정답률 80%
  - 핵심: 조건: 열전도율↓·발열량↑·주위온도↑·표면적↑·적당한 수분. 방지: 통풍·저온·습도 낮게·열 축적 방지
  - 대표 문제: 2022년 2회 15번 — 자연발화가 일어나기 쉬운 조건이 아닌 것
- **몰수·분자량 계산** `원론-기초화학-01` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 73%
  - 핵심: CO2 분자량 44 → 20g ≒ 0.45mol
  - 공식: `n = m / M`
  - 대표 문제: 2022년 2회 3번 — CO2 20g의 몰수 계산
- **개별 물질의 성상 식별** `원론-물질-01` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 70%
  - 핵심: 에틸아민: 상온 무색 기체·암모니아 유사 냄새
  - 대표 문제: 2022년 1회 20번 — 암모니아 유사 냄새의 무색 기체 식별
- **연소의 3요소와 산소공급원** `원론-연소-01` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 71%
  - 핵심: 산소공급원: 공기·산화제(1류·6류)·자기반응성(5류). 탄화칼슘(3류)은 물과 반응해 아세틸렌 발생 → 산소공급원 아님
  - 대표 문제: 2022년 2회 4번 — 산소공급원이 될 수 없는 것
- **가스별 연소범위(폭발한계)** `원론-연소-02` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 74%
  - 핵심: 아세틸렌 2.5~81 / 수소 4~75 / 메탄 5~15 / 프로판 2.1~9.5 / 부탄 1.8~8.4 (vol%). 위험도 H=(U−L)/L
  - 대표 문제: 2022년 2회 17번 — 연소범위가 가장 넓은 가스
- **최소점화에너지(MIE)** `원론-연소-03` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 60%
  - 핵심: 프로판 약 0.25mJ / 수소 약 0.02mJ
  - 대표 문제: 2022년 2회 20번 — 프로판 최소점화에너지
- **전도(Fourier 법칙)** `원론-열전달-01` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 76%
  - 핵심: 열량은 단면적·열전도도·온도차에 비례하고 두께에 반비례
  - 공식: `q = kA(T1−T2)/L`
  - 대표 문제: 2022년 2회 5번 — Fourier 법칙 설명 중 틀린 것
- **정전기 방지대책** `원론-정전기-01` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 77%
  - 핵심: 접지 / 상대습도 70% 이상 / 공기 이온화 / 도체 사용(부도체는 축적 유발)
  - 대표 문제: 2022년 2회 1번 — 정전기 화재 방지대책 중 틀린 것
- **분진폭발을 일으키지 않는 물질** `원론-폭발-01` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 83%
  - 핵심: 시멘트·석회석·탄산칼슘·생석회(산화칼슘)
  - 대표 문제: 2022년 1회 12번 — 분진폭발 위험이 가장 낮은 물질
- **폭연과 폭굉** `원론-폭발-02` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 80%
  - 핵심: 폭굉=화염전파속도가 음속보다 빠름(충격파 동반) / 폭연=음속 이하. 폭굉유도거리는 관지름과 관계
  - 대표 문제: 2022년 2회 14번 — 폭굉 설명 중 틀린 것
### 2. 화재현상 > 1. 화재 및 화재현상

- **화재의 정의** `원론-화재-01` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 83%
  - 핵심: 사람의 의도에 반하거나 고의(방화)로 발생한 연소현상으로서 소화할 필요가 있는 것
  - 대표 문제: 2022년 1회 6번 — 화재의 정의
- **플래시오버** `원론-화재-02` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 82%
  - 핵심: 실내 가연성 기체·열 축적 → 일시에 실 전체 착화(성장기→최성기 전환점)
  - 대표 문제: 2022년 2회 18번 — 플래시오버의 정의
- **화재 관련 국제기구** `원론-화재-03` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 87%
  - 핵심: ISO TC 92 = 화재안전 국제규정 제정 / NFPA = 미국방화협회 / IMO = 국제해사기구
  - 대표 문제: 2022년 1회 4번 — 화재 국제규정 제정 단체
### 2. 화재현상 > 2. 건축물의 화재현상

- **방화구획 면적 기준** `원론-건축-01` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 68%
  - 핵심: 10층 이하 1000㎡(자동식 소화설비 시 3000㎡) / 11층 이상 200㎡(600㎡) / 불연재 내장 500㎡(1500㎡)
  - 법조문: 건축물의 피난·방화구조 등의 기준에 관한 규칙 제14조
  - 대표 문제: 2022년 1회 11번 — 스프링클러 설치 10층 이하 방화구획 면적
- **표준시간-온도곡선** `원론-건축-02` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 72%
  - 핵심: 30분 840℃ / 1시간 925~950℃ / 2시간 1010℃
  - 대표 문제: 2022년 2회 12번 — 표준시간-온도곡선 1시간 경과 온도
- **목조 vs 내화건축물 화재특성** `원론-건축-03` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 74%
  - 핵심: 목조=고온단기형(최성기 약 1100~1300℃) / 내화=저온장기형(약 900~1000℃)
  - 대표 문제: 2022년 2회 16번 — 목조건축물 화재특성 중 틀린 것
- **굴뚝효과 영향인자** `원론-연기-01` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 79%
  - 핵심: 건물 높이·내외부 온도차·화재실 온도·외벽 기밀도 (층 면적은 무관)
  - 대표 문제: 2022년 1회 3번 — 굴뚝효과에 영향을 주지 않는 요소
- **제연설비 풍속 기준** `원론-연기-02` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 71%
  - 핵심: 예상제연구역 유입풍속 5m/s 이하 / 배출기 흡입측 풍속 15m/s 이하·배출측 20m/s 이하
  - 법조문: 제연설비의 화재안전성능기준(NFPC 501) 제8조·제9조 (출제 당시 NFSC 501)
  - 대표 문제: 2022년 1회 5번 — 예상제연구역 유입풍속 기준
- **감광계수와 가시거리** `원론-연기-03` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 77%
  - 핵심: 0.1→20~30m(연기감지기 작동) / 0.3→5m(익숙한 사람 피난 지장) / 0.5→3m(어두움) / 1→1~2m(거의 안 보임) / 10→0.2~0.5m(최성기)

  - 대표 문제: 2022년 1회 19번 — 강화액 소화약제 응고점 기준
- **물 소화약제의 특성** `원론-물-01` — 단골(잠정), 1/2회 출제(1문항), 평균 정답률 80%
  - 핵심: 증발잠열 539kcal/kg·비열 큼·저렴·구하기 쉬움. 금수성 물질과는 반응(화학반응 없다는 지문은 오답)

  - 대표 문제: 2022년 2회 10번 — 탄산수소칼륨+요소가 주성분인 분말 종별
